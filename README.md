# phone

Let your AI agents use your real phone. An MCP server and a companion app,
for OpenCode and any other MCP client.

Hello, world. 🌍📱

## Set up

Tell your agent: *Set up my phone: read https://mobile.orkestrate.space/phone/agent.md*

Or run `curl -fsSL https://mobile.orkestrate.space/phone/install | bash`, then `phone pair` and scan the code with your phone's camera.

- `desktop/`: the MCP server, relay and `phone` CLI (Bun)
- `app/`: the Android companion app
- `site/`: the static pages, installer and `agent.md` for mobile.orkestrate.space/phone
- `protocol/SPEC.md`: wire protocol
