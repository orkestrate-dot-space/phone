# Fonts

- **Inter** (`inter.ttf`) — SIL Open Font License 1.1. https://github.com/google/fonts/tree/main/ofl/inter
- **IBM Plex Mono** (`plex_mono_regular.ttf`, `plex_mono_medium.ttf`) — SIL Open Font License 1.1, Copyright 2017 IBM Corp. https://github.com/google/fonts/tree/main/ofl/ibmplexmono

Sampled to match the type system of the official OpenCode Android app
(Inter for UI text, IBM Plex Mono for machine/code text), itself built on
these same two OFL families.
